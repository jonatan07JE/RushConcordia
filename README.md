# Rush Concordia

Sitio de Rush Concordia. Consulta [SUPABASE_SETUP.md](./SUPABASE_SETUP.md) para configurar Supabase y la publicación automática.

Al abrir esta carpeta en VS Code, la tarea de sincronización automática agrupa los cambios guardados, crea un commit y los sube a `main`. Cada push publica el sitio con GitHub Pages.
